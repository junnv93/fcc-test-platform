# Question Bank — 이 저장소용 한국어 질문

원본(FCC) 질문 은행에서 **이 저장소에 해당하는 것만** 남기고, 이 레인의 판정
규율에서 나온 질문을 더했다. 챔버 축 질문(Excel · 성적서 · 안테나 정규화)은
그 코드가 여기 없으므로 뺐다.

## 상자 경계

- `domain/` · `application/` · `fcc_test_platform/` 는 각각 무엇을 담나?
- 이 저장소를 clone 하면 측정을 돌릴 수 있나? 없다면 무엇이 없나?
- `pyproject.toml` 의 패키지 목록에 없는 모듈은 컨테이너 안에서 어떻게 되나?
- 저장소에 있는 파일과 **배포에 실리는 파일**이 다를 수 있는 이유는?

## 값의 흐름

- 챔버가 보낸 provider 값과 DB 칸에 앉는 값이 다른 이유는?
- 자연키를 uuid 칸에 넣으면 언제 어떻게 드러나나? 조용히 넘어갈 수 있나?
- 해소(자연키 → uuid)가 일어나는 세 가지 형태를 말해 보라.
- 해소를 INSERT 문 안으로 접으면 무엇이 애매해지나?

## 판정

- 응답 200 인데 저장된 행이 0일 수 있나? 어떤 경우인가?
- 그렇다면 인입 성공은 무엇으로 판정해야 하나?
- 밀려남(superseded)을 조용한 성공으로 접으면 무엇이 안 보이게 되나?
- 없는 provider 로 보고가 오면 404 인가 503 인가? 왜 그런가?
- PASS · DRIFT · 판정 불가 셋의 차이를 말해 보라. 셋째를 첫째로 접으면 무엇이 거짓이 되나?

## 검사

- 자동 검사가 전부 초록인데 현장에서 전량 거절될 수 있나? 실제 사례를 설명해 보라.
- 검사용 DB 가 현장 DB 보다 느슨한 자리는 어디인가?
- 봉인을 새로 만들 때 **고치기 전에** 무엇을 먼저 확인해야 하나?
- 「비-공허성 팔」이 없는 초록은 왜 근거가 아닌가?
- 레인 기준선을 줄이는 것과 늘리는 것 중 어느 쪽이 검사를 끄는 것인가?

## 배포

- 「도는 것이 저장소와 같은가」를 무엇으로 판정하나?
- 가장 흔한 배포 결함이 「일어나지 않은 재빌드」인 이유는?
- 마이그레이션 파일이 0개일 때 작업기가 「성공」이라고 답하면 무엇이 문제인가?
- 인증 서버를 다시 만들면 왜 챔버 자격이 사라질 수 있나? 증상은 몇 가지로 보이나?

## 변경 검토

- 이번 수정은 화면 · 경계 · 도메인 서비스 · 어댑터 · DB · 검사 중 어디에 가까운가?
- 이 수정이 성공했다는 증거는 무엇인가? 그 증거가 실측인가 산문인가?
- 검사가 통과했는데 아직 확인되지 않은 시나리오는 무엇인가?
- 같은 파일이 두 저장소에 있으면 무엇이 문제인가? 실제로 무슨 일이 있었나?

## 확인 점검

- 지금 설명한 흐름을 입력 · 처리 · 출력 세 단어로 다시 말하면?
- 이 기능에서 사람이 최종 확인해야 하는 것은 무엇인가?
- 다음에 AI 가 이 영역을 수정하면 어떤 질문을 먼저 해야 하나?
