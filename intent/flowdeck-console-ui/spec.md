## 1. 요구사항

**토큰 · 타이포**

- **R1.** `global.css` 의 primitive 팔레트를 인디고 계열 다크 우선 팔레트로 교체한다.
  강조색(페리윙클)과 상태색(teal/amber/red)은 **서로 다른 색상환**에 둔다 —
  「강조 = 진행 중」으로 읽히는 오독을 막는다.
- **R2.** 라틴/숫자용 서체를 **self-host** 로 추가하고, 한글은 기존
  `Noto Sans KR Variable` 로 폴백시킨다. `--font-sans` 는 스택으로 쌓는다.
- **R3.** 숫자를 쓰는 자리(지표·소요시간·시각·ID)는 고정폭 + `tabular-nums` 로
  렌더해 값이 바뀌어도 자리가 흔들리지 않는다.

**레이아웃 셸 (B)**

- **R4.** 사이드바에 각 항목의 **카운트 뱃지**를 단다. 값이 없으면 뱃지를 그리지
  않는다 — 「0」과 「아직 모름」은 다른 상태다.
- **R5.** 사이드바 하단에 **현황 요약 카드** 하나를 둔다(챔버 가동률).
- **R6.** 상단에 **브레드크럼 + 검색 + 테마 토글** 바를 둔다. 검색은 `⌘K` / `Ctrl+K`
  로 열리고 **Esc 로 닫힌다.**
- **R7.** 페이지 헤더에 **eyebrow**(문맥 한 줄) → 제목 → 요약 문장 순서를 세우고,
  우측에 그 화면의 주요 동작을 놓는다.

**홈 = 운영 콘솔 (C)**

- **R8.** 지표 타일 3개를 보인다. 각 타일은 **자기 데이터 등급을 스스로 안다**:
  - 읽을 수 있는 값(챔버 가동 현황 등)은 **값 + 전일 대비 증감**을 보인다.
    증감은 색과 화살표 **둘 다**로 말한다(색만으로 말하지 않는다).
  - 읽을 계약이 없는 값(실패율·중앙값 소요시간 등)은 **숫자를 지어내지 않고**
    「이 값을 주는 읽기 계약이 아직 없다」를 그 자리에 명시한다.

  ⚠️ **이것은 타협이 아니라 이 레포의 기존 판정을 따르는 것이다.**
  `overview.tsx` 가 이미 그 판정을 주석으로 갖고 있다 — *"Deliberately NOT shown
  (G3 — require backend read contracts): … 내 실패 N건 … They appear only after a
  contract phase, **never faked from partial aggregates**."* 새 UI 가 그 자리를
  그럴듯한 숫자로 덮으면, 이 저장소가 의도적으로 비워 둔 칸을 **UI 사정으로
  채우는 것**이 된다.
- **R9.** 시간대별 **완료/실패 추이**를 하나의 그래프로 보인다.
- **R10.** 챔버별 **성공률 막대** 목록을 보이고, **나쁜 것을 위로** 정렬한다.
- **R11.** 최근 측정 테이블에서 행을 고르면 **우측 패널**에 그 측정의 메타데이터와
  **단계별 진행**이 펼쳐진다. 키보드로도 고를 수 있다.
- **R12.** 데이터가 없을 때(신규 설치·백엔드 부재) 각 위젯은 **자기 빈 상태**를
  그린다. 화면 전체가 에러 하나로 덮이지 않는다.

## 2. 범위 밖 (Non-goals)

* **백엔드 API 를 새로 만들지 않는다.** 필요한 값은 이미 있는
  `/platform/*` 응답에서 파생하거나, 없으면 그 위젯이 「데이터 없음」을 그린다.
* **중앙 DB 스키마·마이그레이션 없음.**
* **`fcc-test-contracts` 를 만지지 않는다** → 커널 태그 발행 없음.
* **다른 라우트를 재디자인하지 않는다.** 24개 나머지 라우트는 R1~R7 의 토큰·셸
  변경을 **자동으로** 물려받을 뿐, 개별 재구성은 이 스펙 밖이다.
* **RBAC 권한을 새로 만들지 않는다.**
* **`⌘K` 팔레트의 «명령 실행»은 넣지 않는다.** 이번엔 **탐색(이동)만**이다.
  명령 실행은 되돌릴 수 없는 동작을 팔레트 뒤에 숨기는 일이라 별도 intent 가 필요하다.
* **모션·트랜지션 체계는 이번 범위 밖이다.** 이 스펙은 «정적인 화면이 무엇을
  말하는가»까지만 다룬다. 부드러운 전환·호버·진입 애니메이션은 `Radiated` 레포에
  이미 다듬어진 것이 있으므로, 그것을 참고 원본으로 삼아 **반응성 작업 때 별도
  intent** 로 올린다. 여기서 어설프게 넣으면 나중에 그 체계와 충돌한다.

## 3. 설계 결정과 근거

| # | 결정 | 버린 대안 | 근거 |
|---|---|---|---|
| D1 | 서체를 **self-host**(`@fontsource/*`) | Google Fonts CDN `<link>` | prod meta CSP 가 `style-src`/`font-src` 에 외부 출처를 두지 않도록 음성 단언돼 있다(`TestDevCspSeparation`). CDN 을 열면 그 봉인을 깨야 하고, 그것은 「보안 헤더를 UI 사정으로 완화」하는 것이다. self-host 는 봉인을 그대로 두고 번들 예산만 재측정하면 된다. |
| D2 | 라틴 서체 + **한글 폴백 스택** | 한글까지 되는 서체 하나로 통일 | 이 컨셉의 인상은 라틴 grotesk 의 좁은 폭에서 나오는데, 그 폭을 가진 서체 중 한글 글리프를 갖춘 것이 없다. 폴백 스택은 한글 화면에서 Noto 로 자연스럽게 떨어지고, 숫자·영문 ID 는 의도한 서체로 렌더된다. |
| D3 | 팔레트를 **primitive 층에서만** 교체 | 컴포넌트마다 색 지정 | 토큰 그래프가 단방향(primitive → semantic → component)이라 primitive 만 바꾸면 25개 라우트가 **한 번에** 따라온다. 실제로 값 29개 교체로 전 화면이 바뀌는 것을 실측했다. |
| D4 | 증감을 **색 + 화살표 + 문구** 셋으로 | 색만(빨강/초록) | 색만으로 정보를 전하면 WCAG 1.4.1 위반이고, 이 레포는 accessibility 를 error 로 게이팅한다. |
| D5 | 성공률 목록을 **나쁜 것 위로** | 이름순 / 좋은 것 위로 | 이 화면의 질문은 「무엇이 문제인가」다. 문제를 스크롤해서 찾게 만들면 화면이 질문에 답하지 않는다. |
| D6 | 차트를 **인라인 SVG 직접 작성** | Recharts/Chart.js 도입 | 의존성 하나가 번들 예산을 크게 먹고, 필요한 것은 면적 2개짜리 추이선 하나다. 라이브러리의 테마 시스템과 이 레포의 토큰 SSOT 가 이중화되는 것이 더 큰 비용이다. |
| D7 | 위젯마다 **독립 빈 상태** | 화면 단위 에러 바운더리 | headless 레인이 없는 환경(모노레포 미보유)에서도 platform 위젯은 살아 있어야 한다. 한 fetch 실패가 화면 전체를 덮으면 「무엇이 살아 있는가」를 잃는다. |
| D8 | 팔레트를 **탐색 전용** | 명령 실행까지 | §2 참조 — 되돌릴 수 없는 동작을 검색창 뒤에 두는 것은 별도 판단이 필요하다. |
| D9 | 지표 타일이 **자기 데이터 등급을 표시** | ① 읽을 수 있는 값만 타일로 만든다 ② 없는 값은 부분 집계로 추정해 채운다 | ②는 `overview.tsx` 가 명시적으로 거부한 것이다(*"never faked from partial aggregates"*). ①은 「왜 여기 실패율이 없나」라는 질문에 화면이 답하지 못하고, 다음 사람이 같은 요청을 다시 가져온다. 등급을 **표시**하면 빈 칸이 «잊힌 것»이 아니라 «아직 계약이 없는 것»으로 읽히고, 그 계약이 생기는 날 채울 자리가 이미 서 있다. |
| D10 | 팔레트를 기존 `SHORTCUTS` SSOT 의 **`search` id 에 붙인다** | 새 `GlobalShortcutId` 를 추가 | `_layout.tsx` 가 `Record<GlobalShortcutId, handler>` 로 **컴파일 타임 완전성**을 강제한다. id 를 늘리면 SSOT·핸들러·도움말 문구가 함께 움직여야 하고, 그중 하나라도 빠지면 tsc 가 막는다 — 즉 늘리는 것 자체가 별도 결정이다. 지금 `search` 는 「첫 입력칸에 포커스」인데, 팔레트가 그 의도의 더 나은 실현이다. |

## 4. 영향받는 경계

* **레인**: `fcc-test-platform` **만**. `fcc-test-contracts` 는 닿지 않으므로
  **커널 태그 선행 불필요**.
* **DB**: 마이그레이션 **없음**. 중앙 DB 사전점검 대상 아님.
* **API 계약**: OpenAPI 표면 **변경 없음** → 아티팩트 재생성 불필요
  (`npm run codegen:check` 는 그대로 초록이어야 한다).
* **프론트엔드**: **시각 골든이 전부 바뀐다.**
  `tests/e2e/ui-visual-regression.spec.ts-snapshots/` 의 PNG 를 재생성한다.
  ⚠️ 골든 교체는 「검사를 끄는 것」과 형태가 같으므로, **교체 전후를 사람이 눈으로
  대조**한 뒤에만 커밋한다. 그 대조가 이 변경의 유일한 시각 판정이다.
* **provider 비공개 레포**: 닿지 않음.
* **package.json**: `@fontsource/*` 2개 추가. `TestPackageJsonInvariants` 는
  **필수 의존의 존재**를 보므로 추가는 통과한다(제거가 아니다).
* **번들 예산**: `bundle-budget.json` 의 `measuredGzipBytes` 를 **재측정 값으로
  갱신**한다. `maxGzipBytes == ceil(measured × headroomFactor)` 파생식은 유지한다 —
  매직넘버를 손으로 적으면 `TestFeP7ProductionGate` 가 막는다.

**Debt-Accepted-By**: (없음)

## 5. 정책 확인

* **인증/RBAC**: 새 권한 **없음**. 홈 위젯은 이미 가진 `platform:read` 로 얻는
  데이터만 쓴다. 권한이 없는 사용자에게는 해당 위젯이 그려지지 않는다
  (`<RequirePermission>` 기존 경로 그대로). 확인함 — RBAC 문자열을 새로 만들지 않았다.
* **개인정보**: 화면에 새로 노출되는 개인 식별 정보 **없음**. 담당자 표시는
  이미 다른 화면(측정 현황)에 있는 것과 같은 표시명이고, 이메일·연락처는 그리지 않는다.
  확인함 — 새 PII 필드를 요청하지 않는다.
* **오프라인 동작**: 서체를 self-host 하므로 **외부 네트워크 없이 렌더된다.**
  이것이 D1 의 부수 이득이다 — CDN 을 썼다면 시험실 오프라인 PC 에서 서체가
  깨졌을 것이다. 차트도 인라인 SVG 라 외부 자원이 없다(D6).
