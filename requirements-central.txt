# ============================================================================
# FCC Central Hub — Container runtime dependencies (B1/P13)
# ============================================================================
#
# This is the dependency SSOT for the *central hub* container image
# (`infra/central/Dockerfile.api`), which runs ONLY the two web surfaces:
#
#   * Headless API   — uvicorn --factory headless_api_app:create_app   (:8001)
#   * Platform API   — uvicorn --factory platform_api_app:create_app   (:8002)
#
# It is deliberately a STRICT SUBSET of `requirements-web.txt`: the desktop /
# chamber-node packages are excluded because the central import closure never
# reaches them. Chamber nodes stay native (GPIB/USB/Nuitka Windows exe) and
# keep using `requirements.txt` / `requirements-web.txt`.
#
# EXCLUDED ON PURPOSE (and SEALED by tests/test_central_docker_compose.py):
#   PySide6              — Qt GUI; the central path is headless (no GUI).
#   pyvisa / pyvisa-py   — GPIB/VISA instrument control; chamber-node only.
#   selenium             — web automation; device-automation only.
#   Appium-Python-Client — appium subprocess; chamber-node only (win32 path).
#   ntplib / pythonping  — NTP/ICMP device utilities; chamber-node only.
#   pyinstaller          — desktop bundler; release build only.
#
# The central runtime is proven win32-free by the import-closure guard in
# tests/test_central_docker_compose.py (no winsound / thread_sampler
# GetThreadTimes / appium subprocess in the central composition).
#
# Install:  pip install -r requirements-central.txt

# ⚠️ Was a TRANSITIVE dependency until 2026-08-21 — it imported on the developer
# machine but nothing declared it, so it would have been ABSENT on a clean central
# host. Local login has no fallback if the hasher cannot import.
# 3.2.0 is the measured floor (bcrypt 3.2.2 is what this repository runs on).
# ⚠️ The 72-byte ceiling is NOT delegated to this library: 3.2.2 silently accepts a
# 73-byte password and 4.x raises. domain/services/password_policy.py refuses it in
# both worlds, so the version floor cannot change login behaviour.
bcrypt>=3.2.0             # Local identity password hashing (EMS parity: cost 12)

# --- Central PostgreSQL ---
psycopg[binary]>=3.1      # PostgreSQL driver for the platform read API + sync
